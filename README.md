An interactive 3D luxury timepiece web application showcasing my software development experience across **backend microservices, AWS cloud infrastructure, Android architecture, and full-stack systems**.

---

## Horological Core Features

- **Interactive 3D Caliber Timepiece**: Fully procedural 3D luxury wristwatch engineered with React Three Fiber, Three.js, physical shaders, and real-time escapement mechanics.
- **12 Dial Hour Navigation**:
  - `12:00` — **HOME** · The Chrono System & Personal Philosophy
  - `01:00` — **ABOUT** · Engineering Profile & Core Architecture
  - `02:00` — **EXPERIENCE** · Professional Timeline (SlickMachine)
  - `03:00` — **PROJECTS** · Systems & Full-Stack Applications (AirVision, PlateShare)
  - `04:00` — **SKILLS** · Technical Repertoire (Java, Python, Spring Boot, AWS, Docker, Kubernetes)
  - `05:00` — **RESUME** · Documentation & Resume PDF Download
  - `06:00` — **POETBYTE** · Creative Digital Expression Portal
  - `07:00` — **ACHIEVEMENTS** · Academic Distinction
  - `08:00` — **RESEARCH** · Published Research Papers (IEEE & International Journals)
  - `09:00` — **CONTACT** · Open Communication & Open Source
  - `10:00` — **PLAYGROUND** · Chrono Lab & Caliber Terminal (`cat bio`, `turbo`, `sudo hire`)
  - `11:00` — **FUTURE** · Future Horizons & What Comes Next
- **60-Minute Tactile Bezel Index**: Interactive bezel increments highlighting specific backend, cloud, and mobile competencies.
- **Caliber Deconstruction**: 7-layer physical mechanical explosion view (Sapphire Crystal, Bezel, Hands, Dial, Case, Movement Engine, Rotor).
- **Interactive Caliber Shell**: Embedded terminal with CLI commands, system diagnostics, and confetti recruitment pipeline.
- **Exhibition Caseback**: 180° rotation revealing the 24K gold skeleton rotor, caliber bridges, and PoetByte creative space.
- **Responsive Architecture**: Fluid side-docked layout on desktop and sleek bottom sheet on mobile devices.

## Technical Stack

- **Frontend & 3D**: React 18, React Three Fiber (R3F), Three.js, `@react-three/drei`
- **Languages**: TypeScript, GLSL shaders, HTML5, CSS3
- **Icons & Effects**: Lucide React, Canvas Confetti
- **Build Tool**: Vite 6, PostCSS
- **Deployment**: Vercel

## Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Vivektheprogrammer/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
